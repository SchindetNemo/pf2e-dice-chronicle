# Dice Chronicle (PF2e)

Automatic roll tracking from Foundry chat messages for Pathfinder 2e on Foundry VTT v14: session history, campaign statistics, awards, and notable moments.

## Install in Foundry

In Foundry's **Add-on Modules → Install Module**, paste this into **Manifest URL**:

```
https://github.com/SchindetNemo/pf2e-dice-chronicle/releases/latest/download/module.json
```

Or download `module.zip` from the [latest release](https://github.com/SchindetNemo/pf2e-dice-chronicle/releases/latest) and extract it into `Data/modules/pf2e-dice-chronicle`.

## Features

- Automatic tracking of every roll in chat; sessions auto-start/end based on connected players
- Live and archived sessions, plus full campaign statistics
- Per-player stats: rolls, dice, crits, fumbles, averages, luck score
- Awards, streak and notable-moment detection, announced in chat
